# Contributing

Audience: contributors
Owner: maintainers
Last Updated: 2025-11-03

- Create a virtualenv; install `requirements.txt`
- Run `python -c "from database.database import init_db; init_db()"`
- Start with `docs/README.md` and `docs/codex/KICKOFF_PROMPT.md`
- Add tests for new logic; mock LLMs in unit tests
- Keep `docs/STATUS.md` and `CHANGELOG.md` updated in PRs
