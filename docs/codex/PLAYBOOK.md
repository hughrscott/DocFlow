# Codex Session Playbook

Audience: Codex sessions
Owner: maintainers
Last Updated: 2025-11-03

Start of Session
- Read `docs/STATUS.md`, `CHANGELOG.md`, and `ROADMAP.md`
- Set exactly one item to In‑Progress in `docs/STATUS.md`
- Add a brief entry to `CHANGELOG.md` with date and scope

During Work
- Update `docs/STATUS.md` if scope changes
- Keep docs aligned with code changes

End of Session
- Move completed items to Done (with date) in `docs/STATUS.md`
- Add a concise `CHANGELOG.md` entry (what changed, key files)
- If priorities changed, reflect in `ROADMAP.md`

Deliverables
- Brief status, endpoints touched, how to run/test, limitations, next steps
